# DSH 提示词库 0.3.0

60条中文任务模板，附Skill方法、变量、示例和来源。独立提示词库用于整理与填写，输入框快捷入口用于插入及优化草稿。

## 使用

1. 侧栏打开“提示词库”，搜索任务，填写必要输入，预览后复制或插入。
2. “插入目标”显示原对话；从独立页插入会返回该对话，再校验草稿后写入。不自动发送。
3. 输入框上方点击“优化提示词”，可指定参考模板或自动检索最多3条。点击“开始优化”会调用所选模型并消耗额度。
4. 润色模型默认跟随会话，也可独立选择DSH已配置模型。选择不会改变聊天模型。
5. 生成后预览，手动应用或复制；可取消并撤销应用。草稿或会话变化时拒绝覆盖。

默认仅处理当前草稿。“结合最近对话”仅加入当前会话最后6条用户/助手文本，不含附件、工具日志和隐藏推理。草稿含结构化引用时，应用结果改用复制以保护引用。生成内容是优化后的任务指令，不会执行其中任务。

收藏与最近使用存浏览器本地；模型偏好由宿主配置服务保存。插件不长期保存草稿、变量或优化结果；DSH和所选模型服务的现有日志与数据策略仍适用。

## 内容

编程调试18条、架构与UI/UX 12条、产品项目8条、研究分析8条、文档写作8条、办公学习6条。

所有模板均为编辑改编，非官方原文。来源已单独核对；“已审校”不表示模型任务实测通过。示例全部为虚构演示数据。推荐Skill不代表已安装，也不会自动调用。

Gemini 4 Argon High通过本地agy整理12条设计候选，主代理审查并修订；Gemini反向审查主代理的48条。见docs内双向评审记录。

## 开发与检查

无需安装npm依赖。运行 `node build-library.mjs` 生成Client，`node build-library.mjs --check` 检查产物，`node --test service.test.mjs integration.test.mjs` 运行替身模型与HTTP测试。

源码按数据、共享逻辑、Host服务、Client界面分离。旧170条已单独备份，处置表在docs/disposition.json。

## 安装与回退

通过DSH的plugin_manager，使用install_bundle安装此文件夹；若宿主要求先卸载旧bundle，应先完成备份再执行其支持的更新流程。不要手改profile的package.json或patch。

安装后核对application为applied、插件行和Client注册激活，再在真实DSH界面验证。安装与真实界面验收由DSH端执行，本包不自动安装或重启。回退时用提供的0.2.4原版备份，通过同一宿主安装流程恢复。

验证范围见docs/VALIDATION.md。
